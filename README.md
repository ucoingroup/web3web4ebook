# 行善三千，

1喝水时默念；愿众生皆得甘露滋养。

2.出行时默念：愿众生出行平安。

3.吃饭时默念：愿所有人衣食无忧。

4购物结账时默念；愿所有人财富自由。

5.看到医院默念；愿所有人平安安健康，无灾无难。

6. 看到学校/幼儿园时默念：
愿所有孩子被爱护，愿所有学子学有所成、心无恐惧。

7. 路过工地/劳动场所时默念：
愿所有劳动者身安体健，愿每一份付出皆有尊重与回报。

8. 看到垃圾车/清洁工时默念：
愿所有清洁者不染尘秽，愿城市因他们而净，他们因善念而得福。

9. 下雨/下雪时默念：
愿雨水洗净众生疲惫，愿雪中之人皆有温暖归处。

10. 看到老人独行时默念：
愿所有暮年被善待，愿孤独者遇搀扶，愿岁月只添皱纹不添病痛。

11. 看到流浪动物时默念：
愿所有弱小生命免于饥寒，愿流浪终有尽头，愿善意成为它们的路标。

12. 开关水龙头时默念：
愿众生皆得清凉与洁净，愿缺水之地涌出甘泉。

13. 点亮灯火/开灯时默念：
愿光照亮所有迷茫的路，愿暗夜中的人心不沉沦。

14. 吃药/照顾病人时默念：
愿此药去除病苦，愿所有受折磨之人早获轻安。

15. 看到警察/消防/医护执勤时默念：
愿守护者亦被守护，愿他们每次出征都平安归来。

16. 听到哀乐/路过殡仪馆时默念：
愿逝者离苦得乐，愿生者哀而不伤，愿所有离别皆有重逢在光明处。

17. 使用电梯/交通工具时默念：
愿所有途中之人无有惊怖，愿每一程都平安到达。

18. 准备入睡前默念：
愿无家者今夜得栖身，愿噩梦远离众生，愿醒来时心怀希望。

19. 看到争吵/冲突时默念：
愿所有愤怒被温柔化解，愿对立双方心中升起理解与宽容。

20. 享用美食/零食时默念：
愿饥者得饱，愿所有生命皆得喜悦滋养。
